# Melhorias Recomendadas

## Prioridade Alta

- Manter o onboarding curto: perfil, objetivos, dias, horário e restrições.
- Usar distância, pace e desempenho apenas a partir dos feedbacks reais.
- Criar uma tela de revisão do plano antes da semana começar, sem permitir que o usuário edite distância ou pace.
- Mostrar explicação objetiva do personal após cada feedback: manter, reduzir ou observar.
- Personalizar meta de água por peso futuramente, mantendo 4.000 ml como padrão inicial.

## Prioridade Média

- Adicionar indicador de aderência semanal no dashboard.
- Mostrar alerta quando houver duas semanas seguidas com baixa frequência.
- Melhorar a análise de queda de desempenho usando média móvel de pace.
- Criar estado de descanso explícito nos dias sem treino.
- Permitir limpar apenas dados de teste, sem apagar todo o histórico do usuário.

## Prioridade Baixa

- Adicionar instalação PWA guiada por plataforma.
- Criar tema de alto contraste.
- Exportar resumo semanal em texto para compartilhamento.
- Adicionar testes automatizados do motor de decisão em arquivo separado.
